# 🛍️ saint2000s — Headless E-Commerce Storefront

*Note: The source code for this project is hosted in a private repository for security and commercial reasons (protecting API keys, customer data, and proprietary business logic). This repository serves as a portfolio showcase of the architecture, tech stack, and UI/UX developed for the brand.*

🔗 **[Saint2000s](https://saint2000s.com)**

## 📖 Overview

**saint2000s** is a modern clothing brand. To provide the best possible user experience, blazing-fast load times, and complete design freedom, we opted for a **Headless E-Commerce** architecture. 

This approach separates the frontend presentation layer from the backend commerce engine, using Shopify strictly as a headless CMS and secure order management system, while the frontend is completely custom-built.

## ⚡ Tech Stack

*   **Frontend Framework:** [Next.js](https://nextjs.org/) (React)
*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Backend / API:** Shopify Storefront API (GraphQL)
*   **Deployment:** Vercel *(Modifie si tu héberges ailleurs, ex: Netlify, AWS)*

## ✨ Key Features & Technical Highlights

*   **Headless Integration:** Seamless fetching of product catalogs, collections, and live inventory data directly from Shopify via GraphQL queries.
*   **Dynamic Cart Management:** Real-time cart creation, product variant selection (sizes/colors), and secure handoff to the Shopify checkout system.
*   **Optimized Performance:** Leveraging Next.js Server-Side Rendering (SSR) and Static Site Generation (SSG) for lightning-fast page loads and top-tier SEO for the clothing catalog.
*   **Responsive UI/UX:** A mobile-first, pixel-perfect design crafted with Tailwind CSS to match the brand's unique aesthetic.
